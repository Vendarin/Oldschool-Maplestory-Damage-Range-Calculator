# README

This tool is used to calculate your damage range based on equips, job, weapon type, spent AP and MW20/30. I use it to check the impact of gear changes mostly. 

Integrating with an equip database proved to have to much difficulties so I opted for a equipment screen where you can just input the stats of the item. This also solved the problem of 'scrolling' the equips in this tool.
